# 爱师大 · 江苏师范大学校园智慧服务

面向江苏师范大学的校园服务门户，按《需求分析.md》v1.0 实现的可运行演示系统。

- 首页：学校概况、师资成就、四校区、地址、占地面积占位、本周日程、2026-2027 校历、信息动态
- 工作通道：实验室预约、空教室预约、图书馆选座、预约审批、资源共享、信息动态
- 生活通道：别名导航、搭子、省钱、互帮互助、自我管理（健身/饮食/计划）、**自我控制**（任务/日程/专注/状态/记录/复盘/成就积分）
- AI 助手：意图识别 + 结构化查询 + 候选推荐 + 用户确认后提交预约
- 我的：预约、签到、取消、省钱与专注统计
- 管理后台：待审批预约、数据概览

## 自我控制（/life/self/control）

在校园门户内的自我控制子工作台，不是独立 App：

- **今日**：状态打卡、今日任务、日程、专注统计、论文卡点、本周完成率
- **计划**：收件箱、已安排、消息转待办（粘贴解析 → 候选 → 创建）、论文阶段推进
- **专注**：25 分钟计时、绑定任务、完成记录；切页不中断
- **记录**：随手记、标签、一键转任务
- **复盘**：周完成率、顺延原因、每日完成率与精力、三条下周重点
- **成就**：积分、等级、8 枚徽章、皮肤商店（校园蓝 / 小狗奶油 200 / 夜读 500）

数据表：`self_tasks`、`self_schedules`、`self_checkins`、`self_notes`、`self_reviews`、`self_papers`、`self_xp`、`self_themes`。
接口前缀：`/api/self/control/*`；首次打开自动写入演示数据与积分。

## 启动

前置：Windows + Python 3.10+（本项目复用 `campus-smart-service/.venv`，也可用系统 Python 安装 `fastapi uvicorn sqlalchemy`）。

```bat
cd campus-smart-agent
start.cmd
```

或手动：

```bat
..\campus-smart-service\.venv\Scripts\python.exe backend\run.py
```

本机打开 http://127.0.0.1:5600 ，同学在同一校园网打开 `http://本机局域网IP:5600`（`start.ps1` 会打印）。停止：`stop.cmd`。

首次让同学访问时，若打不开，右键以管理员身份运行 `allow_firewall.cmd`，放行 TCP 5600。完整说明见 `同学试用说明.md`。

- 端口：5600（避免与旧项目 5500/8000 冲突）；默认监听 `0.0.0.0`，可用 `AISHIDA_HOST`/`AISHIDA_PORT` 覆盖
- 数据库：`data/aishida.db`（首次启动自动建表并写入种子数据）
- 接口文档：http://127.0.0.1:5600/docs
- 健康检查：http://127.0.0.1:5600/api/health

## 演示路径

1. 首页看校情与校历 → 进入工作通道。
2. 实验室：选日期/时段 → 提交 → 在“管理后台”审批 → “我的”签到。
3. 图书馆：选日期/时段 → 点座位 → 确认预约 → “我的”签到。
4. 导航：输入“图书馆/主楼/一餐”→ 选择候选 → 站内地图与步行步骤。
5. AI：输入“明天下午帮我约一个 4 人的研讨教室”→ 候选卡 → 确认预约。
6. 省钱：发布想买 → 投票 → 个人“放弃”后统计增加。
7. 自我管理：番茄钟、身体档案授权、饮食记录、生成周计划。

## 地图导航（真实地图）

- 底图：Leaflet + 高德公开瓦片（HTTPS，免 key），桌面/移动端均可加载
- 地点：坐标来自 OpenStreetMap 实测（敬文图书馆、田家炳工学院、七食堂等 17 个真实地点，已核验；东西南北门为推断位置，标注待核验），入库转为 GCJ-02
- 定位：手机浏览器/微信内置浏览器点“定位到我”，走 Geolocation（WGS-84 前端转 GCJ-02），无需接入微信公众号
- 路线：配置 `AMAP_KEY`（高德 Web 服务 Key，写入 `.env`）后走真实步行路径规划；未配置时画直线并明示“直线距离示意”
- 跳转：每个路线都带“在高德地图中打开”（uri.amap.com，免 key），手机上一键唤起高德 App 做语音导航
- 涉及文件：`backend/app/coords.py`、`web/static/js/geo.js`、`web/static/js/views/nav.js`、`backend/scripts/migrate_places_osm.py`

## 数据边界

- 校情、学院、地址、校历、作息、新闻标题与链接来自江苏师范大学官网公开页面（2026-10-27 采集）。
- 占地面积：官网公开简介未给出数值，页面显示“待校方提供”，不显示猜测值。
- 实验室、教室、座位、路线坐标为**演示数据**，页面均标注；正式上线需实验室管理处/教务处/图书馆/地图服务授权与核验。
- 课表图片未随当前目录提供，系统未据此生成课程或教室数据；OCR 流程在需求文档中定义。
- 外部模型、地图、图书馆系统未接入时走明确降级，不伪造预约号或“已提交学校”的状态。

## 已实现的关键规则

- 预约统一模型：资源、时段、预约、审批、签到；同一资源同一时段冲突校验，待审批占位、拒绝释放。
- 实验室仅工作日开放；面向学院校验；空教室仅 18:30–20:40 借用，排课占用不可选。
- 图书馆座位即时确认，支持签到；座位图按日期/时段显示真实预约占用（另含少量演示占用）。
- AI 不直接下单：返回候选与理由，用户点击“确认预约”后才提交；确认前不占用时段。
- 省钱只统计“已放弃”，改价/撤销/删除同步重算；社区投票不改变个人决策。
- 健康数据需勾选授权后才能记录饮食/生成计划；支持一键删除档案与饮食记录。

## 已知限制 / 下一步

- 未接真实统一身份认证：当前为固定演示账号，正式环境需服务端鉴权与角色校验。
- 未接外部大模型：AI 为规则 + 结构化数据；`services.py` 的意图层可替换为 OpenAI 兼容网关 + SSE。
- 未接高德/校内地图：路线为演示坐标与示意图；正式环境应服务端代理地图 API、前端绘制。
- 未接教务/图书馆/实验室系统：当前为演示数据与站内预约；真实写操作需校方授权。
- 课表 OCR、信息动态自动采集、链接可用性检测、举报审核流为后续迭代。

## 信息架构（v1.2）

- **左侧导航**：校园（首页 / 工作 / 生活）→ 智能（AI 助手）→ 个人（我的），全部展开，SVG 图标 + 分组标题。
- **顶部校区选择**：泉山 / 云龙 / 奎园 / 潘安湖，选择保存在本机；旁边是校园 VR 全景入口（学校公开 720 云链接）。
- **首页**：校园插画头图、校情概览、师资与成就、四校区、校历、动态；每块都可点进详情。
- **详情页**：`/home/about` 学校概况、`/home/faculty` 师资与办学成就、`/home/campus` 校区与 VR（含四校区相对位置示意图）。
- **我的**：新增“自我管理”“自我控制”两个入口；生活通道只保留导航、搭子、省钱、互助。
