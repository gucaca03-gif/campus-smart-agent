## 前提

- 同学需要和你连接**同一个校园网 / 同一局域网**。
- 你的电脑要保持开机，服务不能停止。
- 若同学打不开，先确认你本机能打开 `http://10.19.245.225:5600`；再右键以管理员身份运行 `allow_firewall.cmd` 放行 5600 端口。
- 部分校园网开启了“AP 隔离/客户端隔离”，同 WiFi 设备也不能互访；这种情况需要换网络或使用公网隧道。
